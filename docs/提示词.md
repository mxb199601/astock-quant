# 量化工具提示词

系统规程已经在 `.grok/skills/astock-quant/SKILL.md`（agent 自动加载）。下面是**你对 Grok 说的话**，复制即用。数字必须来自本仓 MCP/`cli.py`，不要让模型上网编行情。

新开一轮对话后再说（本轮若在加 MCP 之前打开，工具列表是旧的）。

---

## 1. 今日操作（最常用）

```
用 astock-quant。先 astock_status，再 astock_action。
只输出：操作口径（空仓/可关注/仅观察）、证据（命令+文件）、若名单非空则反方+失效条件。
红灯必须空仓。MENGα/冷静池/形态不是买点。决策看 PATH+tight，不把 OPT 胜率当实盘。
不荐股。
```

## 1b. 结合网上骨架的复盘（推荐）

```
用 astock-quant 跑 astock_recap（已有日报则 cached=true）。
按输出的 Markdown 给我：结构映射、整体市场、买入向（同行业≤2）、观察层（非买）、反方。
不要再上网搜板块、不要补票凑 3×3、不要写年化或建仓价。
```

## 2. 这只票能不能做

```
用 astock-quant 看 {代码}。
先 status 看红绿灯，再 astock_score {代码} --mode robust，需要的话再 live。
回答只能是：空仓环境 / 仅观察 / 可关注（须在今日 action 候选里）。
给失效条件。禁止「建议买入」。缺数据写缺失，不补猜。
```

## 3. 收盘复盘 / 破戒

```
用 astock-quant 做纪律复盘：astock_discipline，若有 holdings.csv 再 astock_holdings action=check。
对照 playbook：红灯是否空仓、候选是否超出上限、同行业是否>2、浮盈是否触及 -3%。
只报破戒项和文件路径，不另给买入名单。
```

## 4. 回测水分（有人报「七成胜率」时）

```
用 astock-quant：astock_stress sample=400，需要对照再 astock_backtest mode=robust exit=tight。
表格必须分列 OPT 与 PATH。结论只准引用 PATH。
说明：OPT 是窗内极值+先盈后损，会高估；PATH 同日双触先止损。
```

## 5. 观察层（明确不是买）

```
用 astock-quant 跑观察层：astock_alpha top=40，astock_cool top=30。
标题必须写「观察，非买入」。不要把高α/冷静池并进 action。
红灯时只描述冷热，操作口径仍是空仓。
```

## 6. 反方（名单已经出来时）

```
对刚才的候选做魔鬼代言人：红灯切换、PATH 先止损、行业拥挤、成本 50bps、固定持有 up-prob 不占优。
每只给一条失效条件。不允许把观察层顶成买点。
```

## 8. 本仓版「复盘报告」（只借骨架，不借荐股）

```
用 astock-quant 出一份复盘 Markdown，骨架可以像网上那种报告，规则换成下面这些：

1. 先 astock_status，再 astock_action。需要观察层再 alpha/cool，不要用网页热搜凑板块。
2. 红灯：操作口径=空仓；板块/个股章节写「今日无买入向候选」，禁止为了凑满 3 板块×3 只而从冷静池/形态里抽。
3. 绿灯：只列今日 action 候选；按行业分块。某行业不足 3 只就如实写数量，不要补票。
4. 止盈/止损只准写本仓 tight：TP4 / SL3（PATH）。不要推理一套新价位。
5. 禁止出现年化收益目标、机构目标价平均、建仓价。
6. 名单非空必须有反方+失效条件。
7. 结尾一句：研究工具，不构成投资建议。
```
