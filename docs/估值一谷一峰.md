# 估值一谷 / 一峰（观察层）

研究用，**不构成投资建议 / 非荐股**。不进 `joint` / `action`。

## 口径

- 池：主板（含 002），排除 ST、创业板、科创板、北交所  
- **一谷（买入观察）**：近约 3 年价格滚动分位 ≤30%  
- **一峰（卖出观察）**：分位 ≥70%  
- 参考价：最新收盘（可加实时）  
- 本地无 PE 历史时用**价格分位**代理「估低/估高」；CSV 附带当日 PE/PB  

大样本回测（主板、2020 后、约 1 个月）大致：一谷 ~69%，一峰看跌 ~71%。

## 用法

```bash
$PY cli.py gufeng              # 全池扫描，写 output/gufeng_*.csv
$PY cli.py gufeng 002342       # 单票
$PY cli.py gufeng --valley 0.2 --peak 0.85
```

## 买侧底背离（可选）

回测：一谷 ∧ 近 3～5 日底背离，约 68.8%→71.8%（+3pp）。**仅作买侧可选过滤**；不要把放量突破/金叉等做成 AND。卖出一峰逻辑不变。

```bash
$PY cli.py gufeng --divergence              # 默认近5日；写 gufeng_buy_div_*.csv
$PY cli.py gufeng --divergence --div-days 3
$PY cli.py gufeng --divergence --turnover-max 1   # 一谷+底背离+缩量(换手<1%)
$PY cli.py gufeng --divergence --low-turnover     # 同上，默认阈值 1%
$PY cli.py gufeng --divergence --turnover-max 0.5 # 更严：换手<0.5%
```

## 买侧缩量（可选）

回测口径参考：一谷 ∧ 换手<1% win20≈71.0%（+2.1pp）；<0.5%≈72.1%（+3.3pp）。换手取基本面缓存 `turn`（新浪 `turnoverratio`，单位%）。可与底背离叠加；卖出一峰不变。

Web「估值谷峰」勾选 **叠加底背离（买侧）** / **缩量** 后加载：买入列表按勾选过滤。
