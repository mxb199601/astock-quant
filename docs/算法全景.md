## 3. 入场结构（公式三代际）

实现两处（**条件大体对齐，细节有漂移**，见 §7）：

- 历史序列：`factors.formula3_mask`
- 当日截面：`scan.run_structure_scan`

| 模式 | 要点 | 默认用途 |
|------|------|----------|
| base | 大盘多头 + RS + 年线 + 均线多头 + 量 1~3 + 60日涨 0~50% | 最松 |
| strict v2 | + 指数>MA60 + RSI&lt;65 + MA20上行 + zf 5~40 + bias&lt;12 | 观察 |
| elite | + \|bias\|&lt;8 + RS超额≥3% + vr 1.2~2.5 + RSI&lt;62 | 历史主力 |
| winrate v3 | + RSI45~62 + zf5~25 + bias0~8 | OPT 好看 |
| **robust v5** | elite + **zf5~15 + bias0~4** + **指数低波（默认开）** | **扫盘/完整通过默认** |
| `--no-low-vol` | 关闭低波，退回 v4 反热带 | 默认低波**开** |

完整通过（绿灯）：优先 robust → 否则 winrate → 否则 elite-like / strict。  
红灯：`full_pass = []`。

## 4. 出场与回测口径

| 口径 | 规则 | 用途 |
|------|------|------|
| **OPT 乐观窗** | 持仓窗 max(high)/min(low)，**先盈后损** | 参数相对比较；**会高估胜率 ~25–30pt** |
| **PATH 路径** | **逐日**触及；同日双触默认**先止损** | **决策请看这个** |

| 出场档 | 止盈 / 止损 | 备注 |
|--------|-------------|------|
| fixed | 持有到期 | 基准 |
| asym | +8% / −5% | 旧默认 |
| wr | +5% / −3% | OPT 好看 |
| **tight** | **+4% / −3%** | PATH 相对更优；推荐默认 |

压力测试摘要见 `docs/压力测试报告.md`：PATH elite×wr 约 **44%** 胜率，均值仅略正；成本上去易转负。

## 5. MENGα / 联合 / 冷静 / 涨跌

### MENGα v5（`own_alpha.py`）

```
MENGα = -0.60·Heat + 0.15·Wash + 0.20·Spark - 0.10·Crowd
展示 = 全市场截面百分位 0~100
```

- 主轴：**均值回归 / 反过热**（IC：ret60/bias60/excess20 负向）
- 多日截面校验 mean RankIC20 ≈ **+0.074**（高于 v4 约 +0.069）
- **高 α ≠ 买入**；红灯时高 α 常是深跌票

详见 `docs/MENGα自研指标.md`。

### 联合 v2（`joint.py`）

```
完整通过 ∩ (menga≥45 ∧ heat≤55 ∧ spark≥35 ∧ crowd≤75)
排序：qscore 主，menga 辅
```

已弃用「涨跌研究偏多」闸门（WF ~52–54% ≈ 随机）。

### 冷静池 v2（`cool_pool.py`）

α≥85、热≤28、洗≥55、芽≥40、拥≤65、ret60≥−45%、价≥3、RSI≥22。  
**观察池，不是买入名单。**

### 涨跌研究 v3（`forecast.py`）

历史相似 kNN + 距离加权统计；多头门槛抬高。  
**research_value=low**；仅描述/弱刹车，不可作买入依据。

## 6. 形态 / 经典公式 / 妖股（观察层）

### 形态（9）

黄金坑、一阳穿三线、金叉、底背离、放量突破、回踩年线、均线多头、缩量回踩、启明星。  
命中 ≠ 必涨；不进 action。

### 经典公式（12）

dual_mom、rps_break、donchian、ma_squeeze、golden_cross、boll_sq、macd_trend、atr_break、composite、rsrs、kdj_cross、oversold_rebound。  
后三套是 GitHub 公开规则的本地重写（pytrader 的 RSRS、stock_quant 的 KDJ、a-stock-analysis 的五项超跌评分），同样要求大盘站上 MA20，不进入 composite，也不进 action。  
多为突破/趋势；与主板短中期均值回归 IC 常冲突 → 作对照回测，不作主策略。

### 妖股启动前

历史「20 日涨 ≥50%」波段倒推画像，今日匹配打分。  
**低精度高召回**；绝大多数不成妖。

## 7. scan 与 factors：v4.1 已统一

| 层 | 来源 | 说明 |
|----|------|------|
| 公式 base→robust | **`factors.structure_flags_last`** | scan / formula3_today / 打分共用 |
| 历史序列 | `formula3_mask` | 回测；语义与 flags 对齐 |
| 扫盘额外 | `stock_veto`（pe/pb、60低、站MA20） | **仅名单质量**，不在 mask 内 |
| 完整通过 | 仍要求 market_ok（MA20+MA60） | 红灯 full_pass=0 |

红灯下 base 已含 `idx_up` → tech_pass 应很少；观察看 `rs_leaders`。

### PATH 速验（`stress --sample 200`，同日）

| 情景 | n | 胜率 | 均值 |
|------|---|------|------|
| OPT elite×wr | 282 | **71.6%** | +2.43% |
| PATH elite×wr | 282 | **40.8%** | −0.04% |
| PATH elite×tight | 282 | **48.2%** | +0.08% |
| 水分 OPT−PATH（wr） | — | **~30.8pt** | — |

### 多窗口历史验证（`cli.py hist-validate`，600 股×2 seed）

| 命题 | 结果 |
|------|------|
| MENGα mean RankIC20 | **+0.09~+0.10**（24 截面，IC>0 约 67%） |
| robust PATH tight | 胜率 **~53%~56%**，均值 **+0.4%~+0.6%** |
| OPT−PATH 水分 | **~21~31pt** |
| 非绿灯结构信号 | ≈0（公式已嵌 MA20/MA60） |

完整表：`output/hist_validate_summary.md`。

### 固定持有上涨概率（`cli.py up-prob`）

收盘买入、拿满 h 日再收盘卖（**非** OPT/PATH 止盈止损）：

| 口径 | 1～20 日上涨概率（约） | 含义 |
|------|----------------------|------|
| robust/elite/… | 多数 **42%～49%** | **低于或贴近 50%** |
| PATH+tight 盈利概率 | 约 **53%～56%** | 靠止盈止损路径，≠拿满就涨 |

→ 「买入后几天内会涨」的历史概率**并不占优**；纪律出场与死拿满期是两回事。

明细：`output/up_prob_summary.md`。

与全样本压力报告同方向：勿信 OPT 七成；默认出场心理锚点 **PATH + tight**。

## 8. 证据等级

| 等级 | 内容 | 用法 |
|------|------|------|
| **A 纪律** | 红灯空仓（MA20+MA60） | 必须遵守 |
| **B 薄边** | MENGα 反热；robust 反热；PATH 对照 | 研究排序/参数，非稳赢 |
| **C 排序** | quality、联合 α 过滤 | 名单清洁 |
| **D 水分** | OPT ~70% 胜率 | 禁止当实盘胜率 |
| **E 近随机** | 涨跌研究 kNN | 不作闸门 |
| **F 观察** | 形态、妖股、多数突破公式 | 可扫不可主策略 |

## 11. 一句话结论

本系统不是「预测明天谁涨」的黑箱，而是：

**硬风控（大盘） + 薄边结构（robust / PATH） + 反热研究（MENGα） + 大量观察模块。**

没有模块构成投资建议；PATH 期望很薄；红灯必须空仓。
