# 一页执行清单 · 整批筛选 → 打分 → 分散 → 止损

> 目的:把回测验证出的"系统级 edge"(公式三 20日均值 +2.25% / 盈亏比1.68,但胜率仅47%)真正兑现。
> 核心:edge 在"整批 + 分散 + 拿住赢家 + 止损"的纪律里,不在某个名字里。从上往下走,缺一步不做。

---

### STEP 0 · 大盘红绿灯(先看这个,决定今天动不动手)
- 沪深300 / 上证 / 创业板指 是否**都站上 MA20 且 MA20 上行**?
  - ✅ **绿灯** → 可操作(回测里赚钱的环境,后半段均值 +3.34%)
  - ⛔ **红灯**(跌破/MA20下行)→ **空仓或降仓,今天不选股**(回测里这种环境均值 −1.76%,必亏)
- 工具:在 `量化工具/` 目录下 `python score_stocks.py 600519`(任意代码)首行会打印沪深300状态。

### STEP 1 · 整批筛选(不挑)
- 通达信/同花顺跑**公式三**(见操作手册)→ 得到今天**全部**通过的票(约 100–130 只)。
- ❌ 不要只看前几个、不要凭名字挑。整批拿。

### STEP 2 · 打分排序
- 把代码批量丢进 `score_stocks.py` → 按"一票否决 + 加分"排序。
- **只留:一票否决全过 + 加分 ≥5(★强势候选)。** 其余全部丢弃。

### STEP 3 · 人工核三关(机器查不了,任一暴雷直接踢)
- **消息面**:ST/退市风险、监管问询、商誉/质押爆仓、政策利空(如青岛金王的欧盟关税)。
- **资金面**:近期主力**净流入**(不是流出)。
- **业绩**:最近一季净利/扣非**真增长**(不是靠非经常性损益)。
- (这三关把代码发我,我可逐只帮你查。)

### STEP 4 · 分散建仓(关键:别集中)
- 选 **5–8 只**,分散到**不同板块**。
- 单只 ≤ 总仓位 **15–20%**;总仓位看大盘(绿灯可重、刚转绿减半)。
- 留 **≥20% 现金**机动;**分批建,不一次梭哈**。

### STEP 5 · 每只设止损(买入即设,提前挂条件单)
- **跌破买入价 8%**,或**跌破 20 日线放量** → 无条件卖。
- 破位当天手动确认一次(防跌停封单卖不出)。

### STEP 6 · 持有纪律(edge 在这一步兑现)
- 涨的:**让它走**,用移动止盈(回撤 12% 才走)。❌ 别"赚一点就跑"——回测证明那会毁掉盈亏比。
- 跌的:到止损线就走。❌ **别补仓摊成本**。
- 记住:**胜率只有 47%,你会经常错**;钱是靠少数大牛单 + 止损纪律赚的,不是靠每笔都对。

### STEP 7 · 每周复盘
- 重看 STEP 0 红绿灯;转红灯就**整体降仓**,不恋战。

---

## ⛔ 底部红线(永远别做)
- 红灯环境逆势重仓。
- 只买 1–2 只、集中押注(edge 在分散里)。
- 不设止损 / 破位不走 / 补仓摊成本。
- 盯胜率优化、赚一点就跑。
- 听名字买(包括听我的——我不会给,因为给了也是把系统优势变成赌运)。
