## 0. 问题

当前 `lib/feng3.py` 把「摆动高/低」与口语「峰/谷」混用：凡 `[i−k,i+k]` 窗内严格极值即记 top/bot，再 zigzag 交替；「逢3」只是这些摆动里的一个子集触发器。

周易语境下，**峰 ≠ 任意局部高，谷 ≠ 任意局部低**。峰/谷应对应「阳极/阴极而穷」——可检验的极值状态，而非神秘附会。

---

## 1. 典籍锚点（去神秘化）

| 语汇 | 出处/义理 | 可检验读法 |
|------|-----------|------------|
| **阴阳消长** | 《易传》：阴阳此长彼消；「化」为渐进 | 价格过程中同侧摆动序列单调延伸 = 一气之「化」 |
| **物极必反** | 极则向对面转化 | 一侧力量推到不能再同向推进时，才具备反转候选资格 |
| **穷则变，变则通，通则久** | 《系辞下》「易穷则变…」 | **穷**=旧势尽；**变**=阴阳翻转；**通**=新势得以展开 |
| **三变为穷**（操作化借用） | 与「逢3必变」同族：反复三次达穷极 | **同侧第 3 次实质单调延伸**视为穷；非玄学日历 |

陆绩注要旨：阴穷则变为阳，阳穷则变为阴。  
孔颖达：「一阖一辟谓之变」——开闭相循、阴阳递至。

**不做**：卦辞占卜、节气纳甲、等间距「易数」日历、把回测胜率说成天命。

## 2. 峰 / 谷 的周易读法 → OHLC

### 2.1 分层词汇（先正名）

| 易理层 | 市场层 | OHLC 载体 |
|--------|--------|-----------|
| **化**（消长过程） | 趋势腿 / 摆动折点 | zigzag 顶底交替序列 |
| **穷**（极） | **谷 / 峰** | 同侧第 3 次单调延伸之确认点 |
| **变**（翻转） | 反转启动证据 | 穷确认后的对侧摆动，或确认日阴阳翻转 |
| **通**（新势） | 反转后的推进 | PATH：三谷买 → 三峰前卖 |

**结论（正名）**：

- **谷** = **阴穷** = 下行（阴）消长至不能再创新低意义下的第 3 谷确认。  
- **峰** = **阳穷** = 上行（阳）消长至不能再创新高意义下的第 3 峰确认。  
- zigzag 上每一个 top/bot 只是 **折点**（化之迹），**不得直接称为峰/谷**。

### 2.2 操作定义（可回测，主选 v3）

沿用无前视摆动确认：`swing_k`（默认 3），确认日 = `center + swing_k`。

1. **折点**：与现行 `detect_swings` + `build_zigzag` 相同（严格窗内唯一极值、顶底交替、同向取更极端）。  
2. **谷（阴穷）** 当且仅当：  
   - 取 zigzag 最近 3 底 `L1,L2,L3`（时间增）；  
   - **严格** `L3.price < L2.price < L1.price`（真三变；平台相等不算穷）；  
   - 相邻折点腿波幅 `|Li − intervening_top| / Li ≥ min_leg_pct`（默认 3%），保证是实质阴阳消长而非噪声；  
   - 确认日 `close[conf] > close[conf−1]`（**阳始生** = 变之萌芽；无前视）。  
   - 在 L3 **确认日**标记 `kind=谷`。  
3. **峰（阳穷）** 对称：  
   - `H3.price > H2.price > H1.price`；  
   - 腿波幅 ≥ `min_leg_pct`；  
   - 确认日 `close[conf] < close[conf−1]`（**阴始生**）；  
   - 标记 `kind=峰`。  
4. **三谷买 → 三峰前卖 PATH**（股票 only，无 HS300）：  
   - 买：`谷` 确认日收盘；  
   - 卖：下一 `峰` 确认日收盘，若持有窗内无峰则到期卖；  
   - 成本 15bps 往返；主报 5/10/20，补报至峰≤60。

### 2.3 与「物极必反」的对应

- 仅有局部高/低（折点）→ 尚未证明「极」。  
- 三连同向实质下探/上冲 → 进入「穷」的操作区间。  
- 确认日收盘阴阳翻转 → 「变」的最小可观测证据（不是事后完整反转浪）。  
- 完整「通」用 PATH 检验，不在定义里偷运收益。
