# 股票操作手册(基于本人回测验证)

> 本手册由一次完整的数据验证沉淀而成:抓取约 390 只沪深 A 股 2022–2026 前复权日线,
> 复现并回测了多套"牛股/趋势"选股逻辑。下面每条结论都有回测数据支撑,不是口号。
> **核心立场:不存在能稳定选出赢家的公式;能控制的只有"何时参与 + 仓位 + 纪律"。**

---

## 一、回测证明的 5 条真相(反直觉,但是真的)

1. **追涨、突破、回调入场,没有一个有可靠 edge** —— 胜率都在掷硬币(45%–49%)附近。
2. **加止损/止盈能提高"胜率",但会降低"期望"** —— 把胜率从 45.7% 刷到 50.4%,平均收益却从 +1.27% 砍到 +0.71%,盈亏比从 1.51 降到 1.19。**胜率是虚荣指标,期望才是钱。**
3. **唯一稳定有效的杠杆是"大盘择时"** —— 只在沪深300 站上 20 日线时出手,平均收益几乎翻倍(+1.27% → +2.24%)。
4. **决定盈亏的是市场环境,不是选股** —— 所有策略在 2022–2024 弱市全部亏钱,在 2025–2026 全部赚钱。
5. **"破位股会反弹"是幸存者偏差制造的幻觉** —— 回测看不见那些破位后退市/归零的票。**这正是套牢者死扛的心理陷阱。**

## 二、唯一有效的杠杆:大盘择时(先看这个,再谈个股)

**规则:沪深300 / 上证 / 创业板指 —— 看收盘相对 20 日线、60 日线。**
- 三大指数都站上 MA20 且 MA20 上行 → **多头环境,可参与**(数据上是"赚钱的那半段")。
- 指数跌破 MA20、MA20 下行 → **空头环境,降仓/空仓**(任何策略此时都亏钱)。

> 参考状态(2026-06-17 收盘):沪深300/上证/创业板指 **均站上 MA20、MA60 → 多头环境**。
> 每次操作前自己复核一遍当前指数状态。

## 三、选股自检卡(过了第二关的大盘环境,再用这张筛个股)

**第一关 · 5 条一票否决(缺一条直接 pass):**
1. 趋势向上:站上年线(MA250)、年线走平或上翘,非空头排列。
2. 资金没在撤:近 20 日主力资金净流入,或至少不持续流出。
3. 不在下跌通道:不是持续创新低、不是"反弹缩量+下跌放量"。
4. 估值不透支:PE/PB 不在历史极高分位(排除 PB 几十倍的题材泡沫)。
5. 头上没悬顶利空:无退市/ST、无监管点名、无致命政策利空、控制权稳定。

**第二关 · 加分项(过了第一关再数,≥6 条才进自选观察):**
- [ ] 底部横盘缩量 → 均线低位粘合、走平上翘
- [ ] 放量突破平台/年线 + 缩量回踩不破
- [ ] 换手率健康(启动 8–10%、主升 5–10%)
- [ ] 主力 / 北向 / 龙虎榜资金净流入、有知名席位
- [ ] 业绩拐点:单季净利同比转正且加速、ROE>15%、超预期
- [ ] 估值历史低分位(<20%)或 PEG<1
- [ ] 有清晰产业风口 / 主线题材 + 板块联动
- [ ] **强于大盘**(同期跌得少、涨得多)← 回测重点因子

**买点:** 即使打分高,也先放自选,等"放量突破年线 + 缩量回踩不破"的启动确认再买。

## 四、通达信选股公式

### 公式三(推荐,融入回测结论:大盘多头 + 强于大盘)
```
DP:=INDEXC>MA(INDEXC,20);
RS:=(CLOSE/REF(CLOSE,20)-1)>(INDEXC/REF(INDEXC,20)-1);
T1:=CLOSE>MA(CLOSE,250) AND MA(CLOSE,250)>=REF(MA(CLOSE,250),20);
T2:=MA(CLOSE,5)>MA(CLOSE,10) AND MA(CLOSE,10)>MA(CLOSE,20) AND MA(CLOSE,20)>MA(CLOSE,60);
VR:=MA(VOL,5)/MA(VOL,60);  T4:=VR>1 AND VR<3;
ZF:=(CLOSE-REF(CLOSE,60))/REF(CLOSE,60)*100;  T6:=ZF>0 AND ZF<50;
XG:DP AND RS AND T1 AND T2 AND T4 AND T6;
```
筛出后,再叠加通达信"财务选股":净利润同比 > 30%、PE < 80、剔除 ST。然后人工用自检卡逐只打分。

## 五、买卖纪律(唯一能稳定保护你的东西)

- **仓位:** 单只 ≤ 30%,总仓位随大盘环境调整(空头环境大幅降仓)。不满仓押注单一题材。
- **止损:** 买入即设线,跌破无条件执行;别改来改去。
- **止盈:** 不要"涨一点就跑"刷胜率(已证明伤期望);让符合趋势的票按规则走。
- **决策基准:** 永远问"如果空仓,我现在愿意按现价买它吗?" 答否 = 该走。成本价与市场无关。

- 数据已替"还能不能拿"作答:**它们是跑输大盘的弱势股,继续持有 = 用机会成本和下跌风险赌一个数据不支持的反弹。**
