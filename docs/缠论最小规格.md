# 缠论最小可程序化规格（v1）

> 研究用、可回测、无未来函数。  
> **不是**市面缠论软件的完整复刻；派别差异已写死一套规则。  
> 纪律：缠论信号 **永不单独** 作为 `action_today` 买入；默认只作 **否决/过滤/观察**。

---

## 1. 目标

| 目标 | 说明 |
|------|------|
| 可程序化 | 同一段 K 线多次运行结果一致 |
| 无前视 | 分型在右侧 K 收盘后才确认；信号落在确认日 |
| 可对照 | 与 `robust` / PATH+tight 同口径比较 |
| 可回退 | 默认不改 joint / action 主栈 |

---

## 2. 定义（写死）

### 2.1 K 线包含处理

对相邻 K：

- 若 `high[i]≤high[i-1] 且 low[i]≥low[i-1]`（被包含）或反向（包含前一根）→ 合并。
- **合并方向**：由最近一段非包含走势决定  
  - 向上：`high=max`，`low=max`  
  - 向下：`high=min`，`low=min`
- 合并后序列记为 `MH/ML`，并保留每根合并棒对应的 **原序列最后一根 index**（确认时刻）。

### 2.2 分型

在合并序列上：

- **顶分型**：`MH[i] > MH[i-1] 且 MH[i] > MH[i+1]`
- **底分型**：`ML[i] < ML[i-1] 且 ML[i] < ML[i+1]`
- **确认日** = 合并棒 `i+1` 对应的原序列 index（右侧 K 走完才知）。

### 2.3 笔

- 顶底分型 **严格交替**。
- 两分型在合并序列上的间距 ≥ `min_gap`（默认 **4**）。
- 向上笔：底分型 → 顶分型；向下笔：顶 → 底。
- 新分型若与上一笔同向且更极端，则 **延伸** 该笔终点，不新增笔。

### 2.4 中枢

连续 **3 笔** 的价格区间若有重叠：

```
range_k = [min(start_price, end_price), max(start_price, end_price)]  # 按笔端点价
ZD = max(low of 3 ranges)
ZG = min(high of 3 ranges)
若 ZG > ZD → 中枢成立，区间 [ZD, ZG]
```

中枢绑定到构成该中枢的 **第 3 笔结束确认日** 之后生效（无前视）。

### 2.5 买卖点（简化）

| 信号 | 规则 |
|------|------|
| **一买 buy1** | 最近中枢存在；其后出现 **向下离开**（某笔低点 &lt; ZD）；再出现 **底分型确认**，且该底 ≤ 离开低点序列的近期低 |
| **二买 buy2** | 一买低点 L1 已出现；之后上涨再回踩，底分型确认低点 **&gt; L1**，且未有效跌破 L1 |
| **三卖 sell3** | 最近中枢后 **向上离开** 再回落跌破 ZD；反弹高点 ≤ ZG 且 dual 确认 → 做多否决区 |
| **structure_ok** | 当前 **不在** sell3 否决状态（默认 veto 用此） |

参数默认：

| 参数 | 默认 | 含义 |
|------|------|------|
| `min_gap` | 4 | 笔两端分型最小合并间距 |
| `min_bars` | 80 | 最少 K 线才计算 |

## 3. 与本系统的接法

```
formula3 robust  ──┐
                   ├─ robust ∩ structure_ok  → 否决过滤（推荐先做）
缠论 structure_ok ─┘

buy1 / buy2  → 仅观察 / 对照回测，不进 action_today
```

| 层级 | 行为 |
|------|------|
| P0 action | **不改** |
| P1 joint | **不改**（待 PATH 证据再谈） |
| P2 观察 | `cli.py chan` 输出今日结构 |
| 回测 | `cli.py chan --compare`：robust vs robust∩ok vs buy1/2 |

---

## 4. 验证口径

- 主结论看 **PATH + tight + 扣成本**，OPT 仅对照。
- 样本：主板缓存随机抽样（默认 seed=42）。
- 成功标准（升格 joint 前必须满足）：
  1. `robust∩structure_ok` 相对 `robust`：PATH 均值不显著变差，且回撤/连亏有改善；或  
  2. 同均值下 n 下降但夏普/盈亏比明显更好。  
- 任一不满足 → 保持观察层，**不宣称提高上涨概率**。

---

## 5. 已知局限

1. 线段、走势类型、背驰力度 **未实现**（v1 不做）。  
2. 中枢扩展/九段等 **未实现**。  
3. 与通达信/缠论软件画线 **不必一致**。  
4. 历史概率 ≠ 下一笔会涨；红灯仍空仓。
