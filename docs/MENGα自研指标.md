# MENGα 自研指标体系（v5）

> 个人研究工具，非荐股。数据截至本地缓存 K 线。

## 为什么不用「教科书指标」当涨跌基准

对主板约 **600 股 × 历史截面** 做了特征 → 未来 5/10/20 日收益的 Rank IC（`output/alpha_factor_ic.csv`），结论与常见「追强」相反：

| 现象 | 证据 |
|------|------|
| 60 日涨幅越高 | 未来 20 日 IC ≈ **−0.07**（越强越弱） |
| 相对大盘超额 excess20 越高 | 未来 20 日更差；高 RS 五分位均收益仅 ~**+0.25%** |
| 均线多头 / MA20 上行 | IC 为负 |
| **反过热（低涨幅、低 bias）** | IC20 ≈ **+0.07**；Q5−Q1 ≈ **+1.2%** |
| bounce = 5日涨幅 − 20日涨幅 | 中期偏正（IC20 ≈ **+0.044**） |

因此自研主轴定为：**均值回归 + 洗盘深度 + 反弹萌芽 − 拥挤**，而不是金叉/放量突破堆叠。

## 子指标（截面 z 分，当日全市场标准化）

| 名称 | 含义 | 构成（权重） |
|------|------|----------------|
| **Heat 冷热度** | 越高越烫，历史后续偏弱 | 0.40·ret60 + 0.25·bias60 + 0.20·excess20 + 0.10·MA20斜率 + 0.05·RSI |
| **Wash 洗盘深** | 回撤深、中期仍弱 | −0.50·dd60 + 0.10·连阴 − 0.30·ret20 + 0.10·距20高 |
| **Spark 反弹芽** | 短线相对中期止跌回升 | 0.55·bounce + 0.20·近5日上涨量能比 − 0.10·波动比 + 0.15·I(ret5>0) |
| **Crowd 拥挤度** | 量价过热 | 0.45·量比 + 0.55·bias20 |

## 综合分

```
MENGα_raw = -0.60·Heat + 0.15·Wash + 0.20·Spark - 0.10·Crowd
MENGα展示 = 截面百分位 0~100
```

- **高 α**：相对全市场更「冷 + 有洗 + 有萌芽」——统计上短中期略占优，**不是安全垫、更不是必涨**。
- **高 Heat**：近 60 日暴拉/乖离过大 —— 历史对照偏弱。

## 局限

1. IC 量级约 0.05~0.07，**远非稳赢**；胜率约 Top 五分位 51% vs Bottom 44%。
2. 红灯期高 α 往往对应 **深跌票**，波动与基本面风险更大。
3. 未扣停牌/涨跌停/财务雷；未做行业中性。
4. 权重随样本与时段漂移，重大行情后应重跑 IC 再校准。
