# 还能靠什么？边沿优化结论

> 生成依据：`cli.py edge` PATH 阶梯 + 既有 hist/stress/entry_grid。  
> 研究纪律，非荐股。

---

## 1. 先认清：边从哪来

| 来源 | 历史强度 | 是否已落地 |
|------|----------|------------|
| 大盘红绿灯（MA20+MA60） | 强纪律（红灯环境差） | ✅ action 硬闸 |
| robust 反热 + 指数低波 | 中（PATH tight 约 52–56%） | ✅ 默认入场 |
| PATH + tight 出场 | 中（比 OPT/wr 诚实） | ✅ 默认建议 |
| MENGα 冷静联合 | 薄（IC≈+0.09） | ✅ joint 副过滤 |
| **指数环境（20日动量/转绿天数）** | **薄但跨 seed 方向稳** | ✅ playbook 仓位闸 + `boost` mode |
| 组合：分散/仓位/现金/不补仓 | 执行边（清单） | ✅ action playbook |
| 缠论买卖点 | 负 | ❌ 仅观察 |
| 更窄 zf/bias（r_narrow） | **seed 间翻车** | ❌ 不默认 |

**结论：别再堆形态。可靠增量在「少做错误环境 + 出场纪律 + 组合」；因子上只保留有跨样本方向的环境闸门。**

---

## 2. 阶梯实测（PATH × tight × 15bps）

### Seed=42 · sample=350

| variant | n | 胜率 | 均值 |
|---------|---|------|------|
| r_idx_mom0 | 58 | 53.4% | **+0.47%** |
| robust | 64 | 51.6% | +0.33% |
| r_narrow | 31 | 41.9% | **−0.32%** |

### Seed=7 · sample=350

| variant | n | 胜率 | 均值 |
|---------|---|------|------|
| r_boost_narrow | 46 | 67.4% | +1.42% |
| r_green5 / r_boost | 73 | 60.3% | +0.92% |
| r_idx_mom0 | 88 | 58.0% | +0.76% |
| robust | 90 | 56.7% | +0.67% |

解读：

1. **环境类**（指数 20 日>0、转绿≥5 日、boost）两轮都 ≥ robust → 可作 **软闸/仓位**。  
2. **结构再收窄** seed42 差、seed7 好 → **过拟合风险**，禁止写死默认。  
3. 增量是 **百分点零点几**，不是换系统。

---

## 3. 已落地的优化

| 能力 | 用法 |
|------|------|
| 边沿阶梯 | `python3 cli.py edge --sample 350` |
| boost 入场（研究） | `python3 cli.py score 600519 --mode boost` / `backtest --mode boost` |
| 组合 playbook | `python3 cli.py action` 自动打印风险模式/仓位/新建上限 |
| 环境闸门 | 指数 20 日≤0 → 建议 **不新开**；低波+动量>0 → 标准+ |

### playbook 规则（写死）

- 持仓 ≤6 只，单只 ≤15%，现金 ≥25%  
- 出场 tight TP4 / SL3  
- 红灯空仓；非低波/指数 20 日负 → 降仓或禁新开  
- MENGα/缠论/形态/妖股永不单独买入  

---

## 4. 操作优先级（从今以后）

```
P0  红灯空仓 · PATH tight · 分散止损不补仓     ← 最大可控边
P1  只做 action（联合>完整通过）· robust 底仓
P2  指数20日>0 才「标准」新开；否则看 playbook 降档
P3  可选 --mode boost 做更严研究名单
P4  不再加缠论/形态当主信号；edge 定期复跑防漂移
```

---

## 5. 明确不做什么

- 不为「提高胜率」再加难以验证的画线体系  
- 不把单次 seed 的 r_narrow 冠军写进默认  
- 不把 OPT 70% 讲给自己听  
- 成本上去 / 熊市持有期：预期可转负（见压力测试）

## 6. 组合级 PATH（续）

```bash
python3 cli.py edge --portfolio --sample 350
```

政策对照：

| policy | 含义 |
|--------|------|
| all_signals | 有 robust 信号就记一笔 |
| cap3 | 同日最多 3 只（贴均线优先） |
| playbook | 同日≤3 + 并发≤6 |
| playbook_env | playbook + 指数20日>0 才新开 |
| boost_pb | boost 信号 + playbook 约束 |

### 实测（PATH tight，sample=350）

| seed | all 均值 | playbook_env 均值 | MDD all→env |
|------|----------|-------------------|-------------|
| 42 | +0.39% (n=63) | **+0.45%** (n=34) | −17.8% → **−7.7%** |
| 7 | +0.68% (n=81) | **+0.83%** (n=39) | −17.1% → −15.4% |

→ 组合+环境闸：**笔数减少、均值略升、回撤改善**（不是暴利，是可控）。

`action` 已硬接环境闸：指数 20 日≤0（或红灯）→ **空仓(环境)**，原候选进观察列表。

文件：`output/portfolio_path.csv` · `output/portfolio_path_summary.md`

## 8. 行业分散 + 成本压力（续）

```bash
python3 cli.py edge --equity --sample 250
```

### seed=42 · sample=250

| policy | 总收益% | Sharpe | MDD% | cost bps |
|--------|---------|--------|------|----------|
| all_loose | +0.87 | 0.31 | −0.66 | 15 |
| playbook | +2.17 | 0.31 | −1.64 | 15 |
| playbook_env | **+3.44** | **0.51** | −1.24 | 15 |
| playbook_env_ind2 | **+3.44** | 0.51 | −1.24 | 15 |
| **ind2 + cost30** | +1.93 | 0.29 | −1.29 | **30** |
| **ind2 + cost50** | **−0.05** | 0.00 | −2.01 | **50** |

解读：

1. **行业≤2**：本样本与 env 几乎相同（信号稀疏、同行并发少）；全市场 joint 名单多时仍有防扎堆价值 → **action 默认开启**。  
2. **成本 30bps**：收益腰斩仍为正。  
3. **成本 50bps**：期望转负 → 滑点/佣金必须压住；研究默认 15bps 不可当实盘。

action playbook v3：质量排序 → 行业≤2 → 环境闸 → 同日≤3。
