# 压力测试报告（算法 v3 + 栈 v5 备注）

> 样本：主板非 ST 随机 900 股 · elite 信号约 1383 笔 · 持仓 20 日 · 单边成本默认 15bps  
> 生成：`python cli.py stress` → `output/stress_test.csv`  
> **2026-08 栈 v5**：联合信号改用结构∩MENGα（弃用涨跌研究闸门）；出场默认仍看 **PATH + tight**。

## 1. 两种出场口径

| 口径 | 规则 | 含义 |
|------|------|------|
| **OPT 乐观窗** | 持仓期内 `max(high)` / `min(low)`，**先判止盈再止损** | 当前 `backtest` 默认逻辑 |
| **PATH 路径** | **逐日**判断触及；同日双触默认**先止损** | 更接近可执行实盘 |

## 2. 核心结果（elite 入场）

| 情景 | n | 胜率 | 均值 |
|------|---|------|------|
| OPT elite × wr (TP5/SL3) | 1383 | **74.0%** | **+2.62%** |
| PATH elite × wr | 1383 | **44.0%** | **+0.22%** |
| OPT elite × tight | 1383 | 81.2% | +2.38% |
| PATH elite × tight | 1383 | 51.6% | +0.31% |
| OPT elite × asym | 1383 | 58.0% | +2.15% |
| PATH elite × asym | 1383 | 43.3% | +0.24% |
| OPT fixed 20 日 | 1383 | 46.0% | +0.67% |

**胜率水分（乐观 − 路径）≈ +30pt（wr）。**

路径口径下单笔分位：p10=−3.3%（止损）、p50=−3.3%、p90=+4.7%（止盈）→ **超过半数先触止损**。

## 3. 压力维度

### 成本（PATH wr）

| 单边 bps | 胜率 | 均值 |
|----------|------|------|
| 15 | 44.0% | +0.22% |
| 30 | 44.0% | **−0.08%** |
| 50 | 44.0% | −0.48% |
| 80 | 44.0% | −1.08% |

→ 路径下成本一上去期望转负；乐观窗在 cost50 仍显示 +1.9%（**具有误导性**）。

### T+1 开盘入场

| | 胜率 | 均值 |
|--|------|------|
| OPT wr T+1 | 71.4% | +2.41% |
| PATH wr T+1 | 43.0% | +0.14% |

|------|---------------|----------------|

### 最差组合

| 情景 | WR | mean |

| PATH wr + T+1 + cost50 | 43.0% | **−0.56%** |

### 连续亏损（PATH wr）

- 最长连亏：**15** 笔  
- 滚动 50 笔最低胜率：**22%**  
- 最差月例：2026-03 均 −2.34%、胜率 12%（n=25）

## 4. 结论与纪律

1. **宣传/默认回测的 ~70% 胜率不可直接当实盘胜率**；路径口径约 **44%**，均值仅略正。  
2. 高胜率主要来自「窗内极值 + 先盈后损」的统计乐观，不是方向预测变强。  
3. 路径 + 成本 ≥30bps 或熊市持有期 → **期望易转负**。  
4. 系统纪律仍成立：**红灯空仓**；完整通过依赖大盘多头。  
5. 研究用途：OPT 可作参数相对比较；**决策请看 PATH 与压力表**。

```bash
python3 cli.py stress --sample 900
```
