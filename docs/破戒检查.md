# 破戒检查日报

对照 **playbook v3** 审计今日系统输出与可选实盘持仓。  
纪律审计 ≠ 荐股。

## 用法

```bash
# —— 推荐：持仓助手闭环 ——
python3 cli.py holdings init              # 空表
python3 cli.py holdings from-action       # 用今日 action 候选生成草稿（均权）
# 编辑 output/holdings.csv 把 entry_price 改成真实成本
python3 cli.py holdings sync-px           # 刷新现价
python3 cli.py holdings check             # = sync-px + discipline

# 系统自检（无持仓也行）
python3 cli.py discipline

# 批量补行业缓存（行业≤2 更准）
python3 cli.py holdings fill-industry --max 200

# 近14日汇总 / 日更 / Web
python3 cli.py discipline --week
python3 cli.py daily
# Web：python app.py → 「破戒检查」
```

## 持仓 CSV 列（`output/holdings.csv`）

| 列 | 必填 | 说明 |
|----|------|------|
| sym / 代码 | 是 | sh600519 或 600519 |
| weight_pct / 权重% | 建议 | 占总权益比例 |
| entry_price / 成本 | 建议 | 用于止损检查（from-action 默认用现价占位） |
| entry_date / 入场日 | 可选 | YYYY-MM-DD；=今天则算新建 |
| new_today | 可选 | 1/0；覆盖入场日判断 |
| name / 名称 | 可选 | |
| px / 现价 | 可选 | sync-px 自动填 |
| industry | 可选 | from-action / fill-industry 可填 |

## holdings 子命令

| 命令 | 作用 |
|------|------|
| `holdings init` | 建空表 |
| `holdings from-action` | 今日候选 → 草稿（`--merge` 合并旧仓） |
| `holdings sync-px` | 刷新现价 |
| `holdings equal-weight` | 重新均权 |
| `holdings fill-industry` | 批量补行业缓存 |
| `holdings show` | 打印持仓 |
| `holdings check` | 刷新现价 + 破戒检查 |

## 检查项

### 系统侧（S）

| ID | 规则 |
|----|------|
| S1 | 红灯 → action 空仓、buy=0 |
| S2 | 指数20日≤0 → 不新开 / 空仓(环境) |
| S3 | 候选数 ≤ max_new 且 ≤ max_hold |
| S4 | 质量分降序 |
| S5 | 同行业 ≤2 |
| S6 | 出场 tight 提示 |

### 持仓侧（H，需 holdings）

| ID | 规则 |
|----|------|
| H1 | 持仓只数 ≤6 |
| H2 | 现金≥25%、单只≤15% |
| H3 | 今日新建 ≤3 |
| H4 | 红灯/环境闸下不得新建 |
| H5 | 同行业 ≤2 |
| H6 | 今日新建必须 ∈ action 买入候选 |
| H7 | 浮盈触及 −3% 止损 → 严重破戒提示 |

## 输出

| 文件 | 内容 |
|------|------|
| `output/daily/discipline_YYYY-MM-DD.md` | 当日报告 |
| `output/daily/discipline_latest.md` | 最新 |
| `output/discipline_latest.md` | 快捷 |
| `output/discipline_checks.csv` | 检查明细 |
| `output/daily/discipline_week.md` | 近 N 日汇总 |
| `output/discipline_week.csv` | 汇总表 |

持仓现价优先拉 **实时行情**，失败回落日 K；用于 H7 止损检查。

## 退出码

- `0`：无严重破戒（可有 warn）  
- `1`：存在 **crit** 失败（适合 CI / launchd 告警）

严重破戒时 `daily` 会发 macOS 通知「破戒警报」。
